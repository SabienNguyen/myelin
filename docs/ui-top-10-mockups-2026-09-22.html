#62

Check this claim

the aside selection toolbar in Thread.tsx gains a second action · a sibling of /api/aside with its own prompt · effort M

Borrowing lets code use a value without taking ownership. A &mut borrow must be the only borrow of that value while it's in use, which is how Rust rules out data races at compile time.

ask asidecheck this claim
✓ supported2 sources agree · 0 contradict · 1 nuance
✓"At any given time, you can have either one mutable reference or any number of immutable references."
The Rust Programming Language · 4.2 References and Borrowing
✓"…a mutable reference is exclusive for the duration of its use."
vault · Borrowing and slices (cites the Rust Book)
~"While it's in use" is the key phrase: a borrow ends at its last use, not at the end of the scope (non-lexical lifetimes).
Rust Edition Guide · non-lexical lifetimes
