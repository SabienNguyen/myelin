## Graph: the review found more than the perf fix

`graph-perf.e2e.ts` passes: panning p50 is 16.8 ms against the 20 ms target, and the assertion was
not loosened. p95 is 170–270 ms, down from about 405 ms. A trace attributes that remainder to
headless Chromium's software GL. The main thread waits in `GLES2::ReadPixels` during the compositor
commit while the GPU process rasterizes the WebGL canvases in SwiftShader. Measure p95 on real GPU
hardware before tuning further.

The previous agent's fix was sound as far as it went (a scale-free settle check and a run cap).
The review found these defects, each now fixed and tested:

- Every `start()` orphaned a layout supervisor, whose worker and graph listeners stayed alive and
  respawned workers on every poll.
- Overlay positions went through `setState` on every sigma frame, which re-rendered the panel and
  its 5,000-button topic list: about 25 ms of React work per frame. They are now written straight
  to the DOM, and the topic list is memoized.
- `syncGraph` cleared and re-added every edge on every 30 s poll. It now diffs.
- The ForceAtlas2 supervisor owned the position matrix, so a node dragged mid-run never reached
  the worker. It snapped back on every iteration, and its neighbours never followed. Pacing
  iterations to animation frames also tied layout progress to the frame rate, so software GL gave
  hairballs. `layout.ts` now runs its own loop around the package's worker function: the worker
  iterates freely, pinned nodes go into every request, and the graph takes the newest result once
  per frame. Checked in Chromium: the dragged node stays within 2 px of the cursor, and the graph
  follows.
- That loop must send complete FA2 settings; the supervisor used to fill in the defaults. The
  first version did not, and got NaN positions (a 60-page graph drew 16 nodes).
- A settle-check window with no landed iteration counted as "not moving". That froze a 5,000-node
  layout about a second in, on roughly half the runs.
- The settle threshold moved from 0.15% to 1% of the extent. A converged layout with free-running
  iterations still jitters 0.4–0.7% per check.
- Only nodes that draw a ring now get the inflated 1.45× quad.

Screenshots of a 400-page vault and a 27-page topic view, in both schemes, led to three visual
changes:

- **Canvas height.** The 260 px cap now applies only to sparse views (three pages or fewer), as it
  did before the WebGL rewrite. A real graph gets the panel's height, and the topic list below it is
  bounded to 35%.
- **Node size** shrinks with the square root of the page count past the contextual cap
  (`densityScale`). sigma sizes nodes in screen pixels, so at fit every node was full size.
- **Labels.** Views of 12 pages or fewer force every label on. For 13–40 pages only the topic and
  its direct links are forced; the rest go through sigma's collision-avoiding label grid. The
  approved plan forced all of them, which piled titles on top of each other in the core. Hover
  still labels any neighbourhood.

## Chat first: C2 and C3 done

Built as `plans/2026-09-22-chat-first.md` describes. These are the judgement calls the plan did not
spell out:

- `/chat` sets the sticky mode to `''`, not `'chat'`. An explicit mode outranks derivation, so
  "quiz me" would stop reaching quiz.
- Switching threads resets the sticky mode, so a study session stays with its own conversation.
- The session-plan card is a secondary button now, and starting a plan sends `/study`, so the
  tutor works it.
- The follow-up chips need an answer of at least 200 characters, and they hide after a failed
  turn. The store keeps `lastTurnFailed` for that. A reloaded failed turn still shows them, because
  the failure note is plain text.
- `offer_write` is withheld in chat and freeform, which can write directly.
- Chat's empty-vault line no longer says ingest and `create_path` are missing.
- Lesson notes compile a chat turn only if it researched or used a block. "Used a block" means an
  answered block, and those arrive on grading turns, which no mode compiles. In practice a chat
  turn becomes notes when it researched.
