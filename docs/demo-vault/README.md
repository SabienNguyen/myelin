# Demo vault

A real vault, not a synthetic fixture: every page here was researched and written by the live
tutor during one recorded sitting (2026-07-27) in which a learner persona studied transformer
internals and RLHF. The student file is that learner's actual evidence history — machine-graded
computations as `applied-correctly`, model-judged explanations as `explained-correctly`, levels
earned by repetition. One page (`rlhf-reward-model`) is honestly `draft`: the tutor had no
research grant that turn and said so.

Point the app at it to explore: `{"vault": "<absolute path to this directory>"}` in
`harness.config.json` (copy it somewhere writable first — the app records evidence as you work).
